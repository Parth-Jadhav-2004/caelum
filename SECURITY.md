# Reporting security issues

Do not post API keys, audio, transcripts, credential files, signed-in session
information, or unredacted diagnostics in a public issue.

Use GitHub's **Report a vulnerability** entry under this repository's Security
page when private vulnerability reporting is available. If it is unavailable,
open a minimal issue requesting a private reporting channel without including
exploit details or sensitive data. Maintainers must configure that channel;
this document does not promise a response SLA or an already enabled advisory inbox.

Include the affected Caelum version/package, distro/session, a minimal reproduction,
and the expected/observed boundary. Review [docs/privacy.md](docs/privacy.md) and
[docs/ipc.md](docs/ipc.md) before attaching diagnostics. Release-key incident and
recovery procedures are documented in [docs/releasing.md](docs/releasing.md).
